Comment ça marche

Saisissez ou choisissez votre entrée, réglez les options puis lancez l'outil. Lorsque c'est possible, le résultat est généré directement dans votre navigateur.

  1. Entrée: Redimensionneur d'image
  2. Ouvrir l'outil / Calculer
  3. Sortie: Par exemple, choisissez une valeur ou un fichier, modifiez les réglages puis vérifiez le résultat avant de le télécharger ou le copier.
