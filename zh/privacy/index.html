隐私政策

发布前模板：正式发布前，请根据实际运营者、司法辖区、托管、分析和广告配置审查法律文本。

Noreqia Tools 以尽量减少数据收集为设计原则。支持的工具会在浏览器本地处理输入文本和选择的文件。

本网站使用 Google AdSense 展示广告，并使用 Cloudflare Web Analytics 了解网站流量和性能。这些服务可能根据各自的政策和配置处理与网站访问相关的技术信息，例如浏览器、设备、网络和使用情况信息。有关详情，请参阅 Google 和 Cloudflare 的隐私政策。

第三方资源（例如从 CDN 加载的二维码库）可能会收到 IP 地址、浏览器标识等标准网络请求信息。

通过电子邮件发送的联系请求由发送方和接收方的邮件服务商处理。
